## Getting Started  

### 1. Clone the Repository  
```bash
git clone https://github.com/cbiswas32/portfolio.git
```

### 2. Install Dependencies  
```bash
npm install
```

### 3. Run the Development Server  
```bash
npm run dev
```

### 4. Build for Production  
```bash
npm run build
```
